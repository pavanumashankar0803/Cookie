Browser limitations

  • Browsers only expose a cookie's name and value. Domain, Path, Secure and SameSite come from the site profile, or from the Cookie Store API where the browser supports it.
  • HttpOnly cookies can't be read or changed by JavaScript, so the server sets and deletes them.
  • Secure cookies need HTTPS (localhost is the exception), and SameSite=None needs Secure.
  • Domain must be the current host or a parent domain. A non-root Path cookie is only sent on that path.
  • Lifetimes are capped at about 400 days, and a site can hold about 180 cookies.
